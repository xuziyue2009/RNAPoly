# RNA 聚合酶 — 4K 转录音游

一个把 **RNA 转录生物学概念**与 **4K 下落式音游**玩法结合的纯前端小游戏。击打音符 = 合成 RNA 碱基，跟随「RNA 聚合酶」在 DNA 模板上游走转录。

## 🧬 玩法与概念对应

游戏用 `D / F / J / K` 四个键，对应 4 条轨道（lane），每条轨道代表一种 **DNA 碱基**：

| 键位 | DNA 碱基 | 转录出的 RNA 碱基 |
|:---:|:---:|:---:|
| `D` | T（胸腺嘧啶） | A（腺嘌呤） |
| `F` | A（腺嘌呤） | U（尿嘧啶） |
| `J` | C（胞嘧啶） | G（鸟嘌呤） |
| `K` | G（鸟嘌呤） | C（胞嘧啶） |

> 遵循生物学 **碱基互补配对** 规则：DNA 的 T→RNA 的 A、A→U、C→G、G→C。
> 每击中一个音符，就会在 RNA 链上添上对应的 RNA 碱基，直观展示「转录」过程。

## 🎮 玩法机制

- **下落式 4K**：音符沿 4 条轨道落下，在判定线附近按对应键。
- **判定等级**（按按键时机与音符的时间差）：
  - 🔥 `PERFECT`（≤40ms）：300 分
  - ⭐ `GREAT`（≤80ms）：200 分
  - ✅ `GOOD`（≤120ms）：100 分
  - ❌ `MISS`：断连击、不计分
- **连击倍率**：combo ≥50 → 4x、≥30 → 3x、≥10 → 2x、否则 1x。
- **空按惩罚**（严格模式）：按键但没有命中音符会断连击并记一次 miss。
- **结算评级**：准确率 `≥95%` → **S**，`>85%` → A，`>70%` → B，`>50%` → C。

## 🎯 自动采音（MIDI → 谱面）与智能轨道分配

游戏内置 4 首练习曲，源头是 MIDI 音符，通过 `js/midi.js` 的 `parseMidi()` 解析并自动生成下落谱面。

**智能 lane 分配**（`assignLanes()`）—— 旧版直接取模 `midiNote % 4`，会导致某条轨道极密、某条极疏。现改为「**时间序贪心轮转 + 规避连打**」算法：

1. 按音符时间升序逐个处理；
2. 候选轨道优先选「累计负载最小」的，同时**排除与上一音符时间过近的轨道**（避免同轨连打、撞音）；
3. 负载相同时用 **LRU（最久未用）** 轨道，让 4 条轨道自然周转、负载均衡。

效果：4 首曲子在 4 条轨道上分布几乎均匀（如小星星 11/11/10/10、茉莉花 10/10/10/10），且**零撞音**（同轨相邻音符间隔 <90ms 为 0）。

> 该算法在 `js/midi.js` 的 `buildBeatmap()` 中调用，替换音符时无需手动排谱。

## 🧱 项目结构

```
RNAPoly/
├── index.html        # 入口页（SVG 手绘画素材 + 三个界面：标题/游戏/结算）
├── css/
│   └── style.css     # 样式
├── js/
│   ├── config.js     # 全局常量（轨道数、判定窗口、倍率、碱基映射、键位）
│   ├── songs.js      # 曲目表（标题 + base64 编码的 MIDI + BPM）
│   ├── midi.js       # MIDI 解析 + 智能标注音轨分配（核心自动采音）
│   ├── audio.js      # Web Audio 音效/音乐播放（WebAudio API 合成音效）
│   ├── game.js       # 游戏引擎（GameEngine）：主循环、判定、渲染、结算
│   └── main.js       # 启动入口（初始化曲目列表、绑定键盘事件）
└── midi/             # 原始 MIDI 文件（供参考）
```

**加载顺序**（`index.html` 底部）：`config → songs → midi → audio → game → main`，依赖关系严格（前面提供后面所需常量/函数）。

## 🚀 本地运行

用任意静态服务器打开 `index.html` 即可（音游需要音频，建议不要用 `file://` 直接打开，部分浏览器会限制）：

```bash
# 任一方式
python -m http.server 3040
# 或
npx serve .
```

然后访问 `http://localhost:3040`，按空格开始，点击键位可自定义键位映射。

## 🎨 技术亮点

- **纯原生**：无任何前端框架、构建工具，直接浏览器跑。
- **手写 SVG 美术**：RNA 聚合酶酶复合体、DNA 骨架、核苷酸音符、RNA 生长链全部是 `<defs>` 里手绘的 SVG `<g>`，用 `<use>` 复用。
- **Web Audio API**：判定音效（不同等级不同音色）、打击粒子和聚合酶脉冲效果都由代码合成。
- **可玩性细节**：倍速调节、自定义键位、暂停、连击里程碑、结算徽章。

## 📌 已知可扩展方向

- 导入自定义 MIDI 文件生成谱面（`buildBeatmap` 已支持任意 `parsedNotes`）。
- 支持更多轨道（4K → 6K / 7K）。
- 增加曲目的谱面难度标定（Note Density）、长按键（Hold）、双押（Chord）。
